# Code of Conduct

## Our standard

Participants are expected to be respectful, specific, and constructive. Do not
harass, discriminate against, threaten, or deliberately expose another
person's private information. Technical disagreement is welcome when it stays
focused on evidence and the work.

## Enforcement

Project maintainers may remove comments, close issues, or restrict
participation for behavior that violates this standard. Report concerns
privately through the repository's GitHub contact path rather than publishing
private information in an issue.

This project follows the spirit of the Contributor Covenant without claiming
that the full upstream text or enforcement team has been adopted.
