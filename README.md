# Geometry Dash RL AI Agent

Reinforcement learning project exploring an AI agent that learns to play Geometry Dash.

## Status

Project documentation and environment design are in progress. Agent implementation has not started yet.

## Project principles

- Document decisions, experiments, failures, and lessons learned.
- Keep changes small enough that each commit explains one milestone.
- Prefer reproducible experiments with recorded configurations and results.

## Planned direction

- Define the game interaction and observation pipeline
- Select and implement a reinforcement learning approach
- Train, evaluate, and document the agent

See the [roadmap](docs/roadmap.md) and [learning log](docs/learning-log.md) for the project history.
