# Phase 1 status

Phase 1 is being completed as two evidence classes:

1. **Offline-verifiable contracts** are implemented in the package and protected by deterministic tests. These include lazy Win32 loading, injectable platform/capture backends, executable-path validation, ambiguous-window rejection, invalid-handle reacquisition, capture bounds, resize termination, explicit focus policy, action-rate limiting, cursor restoration, emergency stop, canonical states/transitions, diagnostic state info, reset/action guards, contract versions, and the HWC observation declaration.
2. **Live qualification evidence** must be collected against a running Geometry Dash reference setup. It cannot be honestly generated by CI or synthetic frames. The remaining live gates include multi-episode labeled captures, independent annotation agreement, dropped-input/press-duration measurements, detector thresholds and held-out metrics, and the 1,000-step/100-reset reliability run.

## Required live handoff

Before marking the remaining Phase 1 boxes complete, run the project-owned tools with the game started manually and preserve:

- a redacted system/window configuration;
- episode-separated PNG/video captures at the supported resolutions and window positions;
- versioned annotations and an independent second labeling pass;
- machine-readable qualification JSON plus a concise Markdown report;
- selected diagnostic media and checksums linked to the exact Git SHA/config.

The game executable is intentionally never launched by CI. The emergency-stop binding and live capture protocol are documented in `docs/emergency-stop.md` and `docs/experiment-environment.md`.
